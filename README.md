## 🚀 Getting Started

### Prerequisites
- Any modern web browser
- (Optional) A local server tool like VS Code's Live Server extension for the best experience

### Setup
```bash
git clone https://github.com/MiruthyanJayanS/Portfolio.git
cd Portfolio
```

### Running Locally
Simply open `index.html` in your browser, or serve it locally:
```bash
# Using Python's built-in server
python -m http.server
```
Then visit `http://localhost:8000` in your browser.
